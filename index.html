UIlib API DOCS

UI-библиотека хаба: одно окно, категории → табы → секции, семь типов элементов, кейбинды с автосейвом и модальные промпты. Скрипту доступен один объект — LuaApi, его ключ window и есть весь UI. Здесь — всё, что доступно писателю луашек.

getgenv().LuaApi — точка входа одно окно категории → табы → секции 7 типов элементов кейбинды + автосейв промпты: choice / input
01

Quick start

Луашка попадает в хаб двумя путями: кинуть файл в debilizm/luas/ — подхватится автоматически, или добавить прямо в интерфейсе — текстом или ссылкой на raw-текст. Дальше: LuaApi у скрипта не глобал — в начале кода обязательно возьми его из getgenv(). Файл открывает шапка метаданных --# (§02), затем код. Интерфейс строится строго в четыре уровня: категория → таб → секция → элемент.

lua
--# Name: My Farm
--# Author: MARFEL

-- myscript.lua — кинуть файл в debilizm/luas/

local api   = getgenv().LuaApi  -- обязательно первой строкой кода
local UIlib = api.window        -- UI-объект хаба

local cat = UIlib.NewCategory("Мои скрипты")     -- категория (аккордеон слева)
local tab = cat.NewTab("Main")                   -- таб внутри неё
local sec = tab.NewSection("Общее", "left")      -- колонка: "left" или "right"

local tgl = sec.NewToggle("Авто фарм", "my_farm", false)
tgl.OnChanged(function(on)
    print("авто фарм:", on)   -- состояние само сохранится по ключу "my_farm"
end)
конвенция

Дальше по докам UIlib — сокращение для api.window. Сохрани оба локала в начале скрипта, как в примере выше, — и пиши коротко.

важно

Все методы вызываются через точку: UIlib.NewCategory(...), а не UIlib:NewCategory(...) — библиотека не использует self. Двоеточие молча подставит лишний аргумент и всё сломает.

02

Метаданные скрипта

Шапка из комментариев --# в самом начале файла. Хаб читает её при загрузке луашки в список. Главное правило: первые же строки файла — выше не должно быть ничего: ни кода, ни пустых строк, ни других комментариев.

lua
--# AutoExec: true
--# Name: Example
--# Author: MARFEL
--# Created: 7jan 2024
--# Updated: 17aug 2027

local api = getgenv().LuaApi
-- ...дальше код
ПолеЗначениеОписание
NamestringИмя луашки — то, что видит пользователь. Настоятельно желательно
AuthorstringАвтор. Настоятельно желательно
AutoExectrueАвтозапуск: хаб сам запустит скрипт при загрузке, без клика. По умолчанию — выключено
CreatedstringДата создания. Формат свободный, например 7jan 2024
UpdatedstringДата последнего обновления. Обновляй при правках
не обязательно

Ни одно поле не обязательное — скрипт без шапки тоже заработает. Но Name и Author указывай всегда: без них луашка в списке выглядит безымянной, а автор непонятен.

04

UIlib — окно

Окно одно на весь хаб. Из скрипта им управляет только видимость.

#UIlib.Show() · UIlib.Hide() · UIlib.Toggle()

Показать / скрыть / инвертировать видимость главного окна. Toggle — это же UIlib.showhide() (у всех публичных функций есть змеиный двойник).

05

UIlib — промпты

Модальные окна поверх контента: Choice, Confirm, Input, Notify. Все они фризят вызвавший код, пока юзер не ответит — ответ ждётся прямо на месте.

#UIlib.Choice(text, buttons)→ number?

Диалог с произвольным набором кнопок. Возвращает номер нажатой кнопки (с единицы) или nil, если уже открыт другой промпт.

ПараметрТипОписание
textstringЗаголовок промпта
buttons{{string,string}}Массив пар {заголовок, стиль}. Стили: "green" (акцент, для подтверждения) и "gray" (нейтральная, для отмены)
#UIlib.Confirm(text)→ boolean?

Диалог «Отмена / Confirm». true — только если нажата Confirm. Это Choice с двумя кнопками, свёрнутый в одну строку.

#UIlib.Notify(text)→ number?

Одна кнопка «Ok» — для простых уведомлений.

#UIlib.Input(text, placeholder?)→ string?

Поле ввода. Возвращает введённый текст или nil, если нажали отмену.

ПараметрТипОписание
textstringЗаголовок
placeholderstring?Серый текст-подсказка в пустом поле
поток

Промпт фризит код, пока юзер нихуя не впишет / не нажмёт — в этом весь смысл. Из колбэков элементов (OnClick, OnChanged, OnPressed…) зови напрямую, не думая: они и так выполняются в отдельном потоке. Единственное правило — не вызывай промпт в основном потоке скрипта (верхний уровень файла, код подряд без обёртки): там фриз уронит скрипт. Очень надо с верхнего уровня — оберни в task.spawn. И учти: два промпта одновременно не повесятся — пока один открыт, второй сразу вернёт nil.

lua
local btn = sec.NewButton("Спросить", "ask_key")

btn.OnClick(function()   -- колбэк — уже отдельный поток, зови напрямую
    -- Choice: вернёт номер нажатой кнопки
    local n = UIlib.Choice("Продолжаем?", {
        {"Отмена", "gray"},
        {"Ok",     "green"},
    })

    if n == 2 then
        -- Input: строка при подтверждении, nil при отмене
        local name = UIlib.Input("Что фармить?", "Lucky Arrow")
        if name then
            UIlib.Notify("Фармим: " .. name)
        end
    end

    -- Confirm: true / false
    if UIlib.Confirm("Точно?") then
        print("да")
    end
end)

Категория

Аккордеон в списке табов слева. Сворачивается и разворачивается кликом по шапке, высота подстраивается под число табов автоматически.

#UIlib.NewCategory(name, icon?)→ Category
ПараметрТипОписание
namestringЗаголовок категории
iconstring?rbxassetid:// — иконка слева от заголовка. Не задал — пустая

Методы

ВызовОписание

category.OnClick(fn)Сработает при сворачивании/разворачивании категории

local cat = UIlib.NewCategory("Фарм", "rbxassetid://0000000000")

cat.OnClick(function()
    print("категорию свернули или развернули")
end)

-- иконка необязательна:
local cat2 = UIlib.NewCategory("Без иконки")

09

Секция

Колонка элементов в контенте таба: левая или правая. Все элементы создаются только через секцию.

#tab.NewSection(name, holder, icon?)→ Section

Два равнозначных варианта вызова: позиционный — строкой или числом, и таблицей опций. Всё, кроме валидного значения, — ошибка BRO WHAT IS DIS HOLDER?.

ПараметрТипОписание
namestringЗаголовок секции
holdernumber | string | tableПозиционно: 1/"left" — левая колонка, 2/"right" — правая. Или таблица опций: { side = …, holder = …, icon = … }
iconstring?rbxassetid:// рядом с заголовком — только в позиционном варианте; в табличном передаётся ключом icon

Табличный вариант

Второй аргумент — таблица: ключи side и holder взаимозаменяемы, icon — иконка в заголовке. Если колонку не указать, секция создастся в левой.

lua
local right = tab.NewSection("Разное", {
    side = "right",                -- "left" / "right"; то же, что holder = 2
    icon = "rbxassetid://0000000000",
})

-- колонку можно вообще не указывать — будет левая:
local plain = tab.NewSection("Общее", { icon = "rbxassetid://0000000000" })

Позиционный вариант

lua
local left  = tab.NewSection("Общее", "left")
local right = tab.NewSection("Разное", "right")

-- 1 и 2 значат то же самое:
local l = tab.NewSection("Общее", 1)
local r = tab.NewSection("Разное", 2)

-- с иконкой:
local r2 = tab.NewSection("Разное", "right", "rbxassetid://0000000000")

Элементы — Dropdown

#section.NewDropdown(name, values, cfg_key?, values_cfg?, mode?, min_selected?)→ Dropdown

Выпадающий список. Значения передаются вторым аргументом, опции — либо позиционно, либо третьим аргументом-таблицей. Режим по умолчанию — multi.

ПараметрТипОписание
namestringЗаголовок
valuestableОпции: "Строка" или { "Имя", выбран? }. Строковые ключи таблицы становятся ключами опций — их потом ждёт RemoveValue и колбэк
cfg_keystring?Ключ сохранения состояния (что выбрано)
values_cfgstring?Ключ сохранения самого списка: если задан, сохранённый список заменяет значения по умолчанию при загрузке
modestring?UIlib.types.dropdown.single / .multi
min_selectednumber?Меньше стольких выбранных оставить нельзя — при попытке снимется Notify; при 1 последний просто не снимается

Или всё сразу таблицей:

lua
local dd = sec.NewDropdown("Цели", {
    "Melee",                -- не выбрана
    "Ranged",
    { "Bosses", true },     -- выбрана
}, {
    mode        = UIlib.types.dropdown.multi,
    minSelected = 1,
    config      = "my_targets",   -- сохранит состояние
    -- valuesConfig = "my_list",  -- сохранит сам список опций
})

Методы

ВызовОписание
dd.OnChanged(fn)fn(values, key, state): values — вся таблица опций (key → { имя, выбран }), state — true/false при переключении, nil при удалении опции
dd.AddValue(name, selected?)Добавить опцию на лету
dd.RemoveValue(key)Удалить опцию по ключу; если она была выбрана — колбэк получит state = nil
нюансы

В режиме single выбор новой опции автоматически снимает старую. При регистрации OnChanged после создания библиотека дозовет колбэк для каждой существующей опции с её текущим состоянием. Удалённая при открытом списке опция помечается [DELETED] и краснеет — до закрытия списка.

lua
dd.OnChanged(function(values, key, state)
    if state == nil then
        print("опцию удалили:", key)
    else
        print(values[key][1], "→", state)
    end
end)

dd.AddValue("Стенды", false) -- добавить на лету
dd.RemoveValue(2)            -- удалить по ключу
14

Элементы — Keybind

#section.NewKeybind(name, default?, config?)→ Keybind

Бинд на клавишу. Юзер биндит один раз — клавиша сохраняется в конфиг и при следующем запуске подтягивается сама. Можно задать клавишу по умолчанию, если юзер ещё ничего не биндил.

ПараметрТипОписание
namestringТекст слева
defaultstring?Клавиша по умолчанию, например "K" — подставится, если юзер ещё ничего не забиндил
configstring?Ключ автосейва: забинженная клавиша сохранится и подтянется при следующем запуске

Табличный вариант

lua
local kb = sec.NewKeybind("Паника", {
    default = "K",
    config  = "my_panic",
})

Позиционный вариант

Порядок: (name, default, config) — не перепутай: второй аргумент это дефолтная клавиша, а не ключ конфига.

lua
-- с дефолтом:
local kb = sec.NewKeybind("Паника", "K", "my_panic")

-- без дефолта — юзер забиндит сам:
local kb = sec.NewKeybind("Паника", nil, "my_panic")

Методы

ВызовОписание
kb.OnPressed(fn)Колбэк при нажатии забинженной клавиши, вызывается без аргументов
kb.GetKey()Текущая клавиша ("F", "K"…) или nil, если бинда нет
kb.IsHolding()Клавиша зажата прямо сейчас — для «пока держим»-логики
lua
local kb = sec.NewKeybind("Паника", "K", "my_panic")

kb.OnPressed(function()
    print("нажали!")   -- сработает на каждое нажатие K
end)

print(kb.GetKey())     -- "K" / "F" / nil (бинда нет)
print(kb.IsHolding())  -- зажата ли прямо сейчас
15

Элементы — Slider

#section.NewSlider(name, default?, min?, max?, config?, decimals?, rounding?, storeRounded?)→ Slider

Числовой слайдер с автосейвом, ручным вводом значения и сменой границ на лету. Аргументы можно передать позиционно, одной таблицей или смешанно (таблица вместо хвоста аргументов). По умолчанию: 0 … 1.

ПараметрТипПо умолчаниюОписание
namestring—Текст сверху
defaultnumber?0Начальное значение; при наличии config сохранённое побеждает
min / maxnumber?0 / 1Границы
configstring?—Ключ автосейва
decimalsnumber?1Знаков после запятой в поле значения
roundingstring | number?—Округление отображаемого значения: "ceil" — вверх, "round" — к ближайшему, "floor" — вниз, "none" / не задано — сырое. Числами то же самое: 1, 0.5, 0
storeRoundedboolean?falseХранить округлённое (и обрезанное до decimals) значение, а не сырое положение ползунка — его же получат колбэк и конфиг

Табличный вариант

lua
local sl = sec.NewSlider("Скорость", {
    default  = 25,        -- можно писать value = 25 — то же самое
    min      = 1,
    max      = 100,
    config   = "my_speed",
    decimals = 0,
    rounding = "ceil",
})

Позиционный и смешанный варианты

lua
-- всё позиционно:
local sl = sec.NewSlider("Скорость", 25, 1, 100, "my_speed", 0, "ceil")

-- или хвост таблицей:
local sl = sec.NewSlider("Скорость", 25, 1, 100, {
    config   = "my_speed",
    decimals = 0,
    rounding = "ceil",
})

Методы

ВызовОписание
sl.OnChanged(fn)fn(value: number) — на каждое движение ползунка, на Set и на ручной ввод
sl.GetValue(rounding?)Без аргумента — сырое значение; true — округлить по rounding слайдера; 1/0.5/0 — задать режим вручную
sl.Set(value)Выставить значение программно (клампится в границы)
sl.GetLimits()→ min, max
sl.GetMin() / sl.GetMax()Границы по отдельности
sl.SetLimits(min?, max?, clamp?)Сменить границы; clamp = true — втащить текущее значение в новый диапазон
sl.SetMin(min, clamp?) / sl.SetMax(max, clamp?)Частные случаи SetLimits
lua
local sl = sec.NewSlider("Скорость", {
    default = 25, min = 1, max = 100,
    config  = "my_speed", decimals = 0, rounding = "ceil",
})

sl.OnChanged(function(v)
    print(v)             -- 1 … 100
end)

print(sl.GetValue())     -- сырое значение
print(sl.GetValue(true)) -- округлённое по "ceil"
sl.Set(50)

print(sl.GetLimits())    -- 1, 100
sl.SetLimits(1, 500, true)  -- расширить и втащить значение в диапазон
sl.SetMin(0)
sl.SetMax(1000, true)
ручной ввод

Значение можно вписать руками в поле рядом с дорожкой.

Элементы — Color

#section.NewColor(name, default?, config?, transparency?, palette?)→ Color

Выбор цвета с попапом: HSV-поле, ползунок оттенка, ввод RGB/HEX и опциональные прозрачность и палитра пресетов (в том числе "Rainbow" — цвет переливается сам). Цвет можно передавать и как Color3, и строкой — "#FF0000" или "255, 0, 0".

ПараметрТипОписание
namestringТекст элемента
defaultColor3 | string?Начальный цвет (Color3, hex или RGB-строка); при наличии config сохранённое побеждает
configstring?Ключ автосейва
transparencynumber?Число 0–1 — начальная прозрачность; сам факт передачи включает в попапе ползунок прозрачности. Без него слайдера нет
paletteboolean | string?Включить панель пресетов. Строка — включить и сразу активировать пресет, например "Rainbow"

Табличный вариант

lua
local cp = sec.NewColor("Трейсеры", {
    default     = Color3.fromRGB(0, 200, 255),
    config      = "my_color",
    transparency = 0.2,   -- включит ползунок прозрачности
    palette     = true,   -- включит панель пресетов
})

-- пресет сразу:
local rb = sec.NewColor("Акцент", { palette = "Rainbow" })

Позиционный вариант

lua
-- name, default, config, transparency, palette:
local cp = sec.NewColor("Трейсеры", "#00C8FF", "my_color", 0.2, true)

Методы

ВызовОписание
cp.OnChanged(fn)fn(color, transparency) — два значения: цвет (в активном пресете — из пресета, Rainbow живой) и прозрачность. Срабатывает на движение, ввод RGB/HEX и выбор пресета
cp.GetColor()Текущие color, transparency (cp.Color() — то же). В Rainbow цвет актуален в момент вызова
cp.SetColor(color)Задать цвет программно: Color3, "#RRGGBB" или "R, G, B" (cp.Set — то же). Зовёт колбэк
lua
local cp = sec.NewColor("Трейсеры", { config = "my_color", palette = "Rainbow" })

cp.OnChanged(function(c, t)
    print(c, t)   -- Color3 и прозрачность
end)

local c, t = cp.GetColor()   -- в Rainbow каждый вызов — новый цвет
cp.SetColor("#FF0000")       -- или Color3.fromRGB(255, 0, 0)
rainbow

Активный пресет "Rainbow" живёт сам: свотч переливается каждый кадр, GetColor() и колбэк возвращают актуальный цвет. Двигать HSV-поле при активном пресете бесполезно — цвет берётся из пресета, пока пользователь его не снимет.

LuaApi — точка входа

LuaApi — единственный объект хаба, доступный скрипту. Это не глобал: в начале кода обязательно возьми его из getgenv(). Из ключей: window/ui — сам UI, остальное — служебное.

КлючОписание
window / uiUI-объект UIlib — две ссылки на одно и то же. Все методы этих доков: NewCategory, Choice, Input…
categoriesДерево созданных узлов (категории → табы → секции → элементы) — см. ниже
instanceРеальный ScreenGui окна. Низкий уровень — лезть туда стоит только если очень надо
windowdataВнутренние таблицы хаба; то же, что UIlib.windowdata и UIlib.datalink. Для отладки
PrintHierarchy()Печать текущей иерархии в консоль и возврат дерева узлов
lua
local api    = getgenv().LuaApi  -- обязательно первой строкой кода
local UIlib  = api.window        -- == api.ui
local window = api.instance      -- ScreenGui окна
local tree   = api.categories    -- дерево узлов
api.PrintHierarchy()             -- дерево в консоль

Дерево categories

api.categories — таблица по именам: каждый узел хранит своё name, control (API-объект этого уровня) и детей. По дереву можно добраться до любого созданного элемента, не храня ссылки самому:

api.categories[categoryName]
└─ name · control · tabs
   └─ api.categories[…].tabs[tabName]
      └─ name · control · sections
         └─ api.categories[…].tabs[…].sections[sectionName]
            └─ name · control · elements
               └─ api.categories[…].…elements[elementName]
                  └─ name · control
lua
-- добраться до контрола слайдера по имени:
local sl = api.categories["Settings"].tabs["Settings"]
           .sections["Gui"].elements["UI Scale"].control

-- то же самое, что local sl = sec.NewSlider("UI Scale", ...) из скрипта

Конфиг и кейбинды

У элементов с аргументом cfg_key / config состояние сохраняется в debilizm/njrat.virus.CFGv1.fatrat (JSON) — мгновенно при изменении, без ручного сохранения. При следующем запуске значения подтягиваются сами.

Ключ в конфигеЧто хранитКто пишет
cfg.keybindscfg_key → имя клавиши ("F", "K"…)NewKeybind, NewButton
cfg.valuesСостояния тогглов, слайдеров и цветовNewToggle, NewSlider, NewColor
cfg.otherСостояния и списки дропдауновNewDropdown (ключи config / valuesConfig)
  • cfg_key — любая уникальная строка на твой вкус: "my_farm", "tp_key".
  • Придумал один раз — не переименовывай между версиями скрипта: старое значение по новому ключу не подтянется.
  • Хочешь сбросить всё — удали файл конфига, библиотека создаст новый.
  • Формат файла внутренний; писать туда руками не нужно — только через элементы.
20

Нюансы и подводные камни

  1. Точка, не двоеточие. Библиотека без self: UIlib.NewCategory(...), sec.NewToggle(...). Двоеточие подаст таблицу первым аргументом и всё поедет.
  2. Мета — первыми строками. Над блоком --# в файле не должно быть ничего, иначе хаб его не прочитает.
  3. Промпты — не в основном потоке. Они фризят код до ответа юзера — в колбэках элементов можно, на верхнем уровне скрипта нельзя (оберни в task.spawn, если очень надо).
  4. Два промпта не откроются. Пока один висит, второй вернёт nil сразу — закладывай проверку, если промпты могут пересечься.
  5. Дубликаты имён. Два элемента с одинаковым именем — не ошибка: библиотека молча добавит пробел в конец имени узла. Учитывай при поиске по api.categories.
  6. Первый вызов OnChanged у дропдауна придёт для каждой существующей опции с её текущим состоянием; у тоггла, слайдера и цвета с config сохранённое значение дозовётся при старте — не удивляйся очереди событий.
  7. single-дропдаун сам снимает прошлый выбор; minSelected не даст снять последний (при 1 — молча, при большем — с Notify).
  8. Цвет в колорпикере при активном пресете берётся из пресета — HSV-поле до его снятия ничего не меняет.

Полный пример

Всё API в одном скрипте — скопируй в debilizm/luas/full_example.lua и запусти из списка.

lua
--# AutoExec: false
--# Name: Full Example
--# Author: MARFEL
--# Created: 7jan 2024
--# Updated: 17aug 2027
-- full_example.lua — кинуть в debilizm/luas/

local api   = getgenv().LuaApi  -- обязательно первой строкой кода
local UIlib = api.window        -- UI-объект хаба

-- == структура ==
local cat   = UIlib.NewCategory("Stand farm", "rbxassetid://0000000000")
local tab   = cat.NewTab("Main")
local left  = tab.NewSection("Фарм", "left")
local right = tab.NewSection("Разное", { side = "right" })

-- == лейбл-статус ==
local status = left.NewLabel("Статус: ожидание")

-- == тоггл, автосейв по ключу "farm" ==
local auto = left.NewToggle("Авто фарм", "farm", false)
auto.OnChanged(function(on)
    status.SetText("Статус: " .. (on and "фармим" or "ожидание"))
end)

-- == слайдер: 1..100, целые, автосейв ==
local speed = left.NewSlider("Скорость", {
    default  = 25,
    min      = 1,
    max      = 100,
    config   = "speed",
    decimals = 0,
    rounding = "ceil",
})
speed.OnChanged(function(v)
    print("скорость:", v)
end)

-- == дропдаун: мультивыбор, минимум один, сохранение ==
local dd = left.NewDropdown("Цели", {
    "Melee", "Ranged", { "Bosses", true },
}, {
    mode        = UIlib.types.dropdown.multi,
    minSelected = 1,
    config      = "targets",
})
dd.OnChanged(function(values, key, state)
    if state ~= nil then
        print(values[key][1], state)
    end
end)

-- == кнопка с хоткеем и промптом ==
local tp = right.NewButton("Телепорт", "tp_key")
tp.OnClick(function()
    -- колбэк и так в отдельном потоке — промпты зовём напрямую
    if not UIlib.Confirm("Телепорт к стендам?") then return end
    local what = UIlib.Input("Что ищем?", "Lucky Arrow")
    if what then
        status.SetText("Ищем: " .. what)
        UIlib.Notify("Погнали")
    end
end)

-- == цвет с прозрачностью и палитрой ==
local tracer = right.NewColor("Трейсеры", {
    config       = "tracer",
    transparency = 0.2,
    palette      = "Rainbow",            -- пресет сразу активен
})
tracer.OnChanged(function(c, t)
    print(c, t)                          -- Color3 и прозрачность
end)

-- == паническая клавиша (K по умолчанию) ==
local panic = right.NewKeybind("Паника", "K", "panic_key")
panic.OnPressed(function()
    UIlib.Hide()                         -- спрятать окно
end)

UIlib.PrintHierarchy() -- всё дерево в консоль
